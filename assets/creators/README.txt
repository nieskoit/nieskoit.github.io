WŁASNE PROFILOWE TWÓRCÓW
==========================

Wystarczy wrzucić własne pliki WebP do tego katalogu:

  nieskot.webp
  kaicek.webp
  dombeek.webp
  pawelul.webp

HTML automatycznie użyje WebP jako profilowego.

Jeżeli pliku WebP nie ma, zostaje użyty obecny SVG jako fallback.

Zalecenia:
- kwadrat: np. 512x512 px lub 1024x1024 px
- WebP
- bez przezroczystego marginesu wokół postaci/logo
- nazwa pliku musi odpowiadać nazwie twórcy powyżej
